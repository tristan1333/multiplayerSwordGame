# multiplayerSwordGame
A multiplayer game! Compiled with SDL2, SDL2_TTF, SDL2_image, and eNet
IMPORTANT: ip.txt must be editted to set the server IP which is initially set to 127.0.0.1, the host will need to portforward on port 10558
Gameplay: WASD to move, F/G to rotate the sword. Hit the opponent while not facing the same direction to win!
